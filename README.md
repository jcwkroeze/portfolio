# Portfolio Website

A simple static portfolio website. Host the contents of this folder on S3 or any static web host.

## Structure
- `index.html`: Home page with a grid of project screenshots
- `style.css`: Styles for the site
- `script.js`: Handles grid rendering
- `projects/`: Project pages and assets (screenshots, webms)

## Usage
1. Add your project thumbnails and webms to `projects/`
2. Edit `script.js` to add your real projects
3. Add a `projectX.html` file for each project, with embedded webms
4. Upload to S3 (or any static host)

---

Feel free to customize the design and structure!
